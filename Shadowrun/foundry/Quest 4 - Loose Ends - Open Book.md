# Open Book

## Accroche

Entre les commlinks Renraku Sensei du butin original et ce qui a été récupéré sur les Nettoyeurs, Bricks a de quoi tirer des fils. Job de terrain/Matrice -- son moment.

## Phase 1 -- Le grand livre

Registre financier chiffré (Computer/Hacking, test étendu, seuil 12, intervalles 10 min) relie le financement du **Dr. Sebastian Grogg**, via deux sociétés-relais, à une société-écran seattloise : **Hollow Pine Holdings**.

## Phase 2 -- Creuser Hollow Pine

Les registres publics font impasse -- Hollow Pine est une coquille immobilier/conseil avec un seul dirigeant enregistré : **Dorian Ashe**. Pirater le host ou accéder physiquement au bureau (Corp Lobby).

## Phase 3 -- Le host

Host Hollow Pine Holdings -- Rating 5 (Attack 6 / Sleaze 8 / Data Processing 5 / Firewall 7). Une IC de patrouille, escalade possible vers une Standard Security Spider. Gagnable pour un seul decker -- c'est un relais, pas la vraie cible.

## Phase 4 -- La révélation

Un vieux numéro de dossier fait référence croisée à une enquête interne Knight Errant classée -- le dossier de l'escouade de Bricks. Le fil qu'elle tire depuis des années et la corpo que le groupe vient d'exposer ne font qu'un.

## Récompenses

Pas de paiement direct, 2 Karma pour le travail de terrain, ouvre "Windows Open" (Acte 2). Bonus optionnel : Bricks peut ponctionner quelques milliers de nuyens sur un compte discrétionnaire Hollow Pine (au MJ de juger l'attention que ça attire).

*Cartes suggérées : Hacker's Lair, Server Room ou Corp Lobby.*
